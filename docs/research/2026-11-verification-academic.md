## Reinhart per-1k rates, recomputed

The PNAS SI PDF was unreachable, so these rates come from the paper's own public feature file (`https://cmustatistics.github.io/data-repository/data/hap-e-biber.csv.gz`, pseudobibeR features, rates per 1,000 words, 8,290 texts per source). The recomputed ratios match the paper's 5.3x and 2.1x, so the file is the same data the paper used. These are means, not the SI table values.

| Source | Present participial clauses per 1k words | Nominalizations per 1k words |
| --- | --- | --- |
| Human, chunk 2 | 1.73 | 14.6 |
| GPT-4o (2024-08-06) | 9.09 (5.27x) | 31.3 (2.14x) |
| GPT-4o Mini | 8.30 (4.81x) | 30.5 (2.09x) |
| Llama 3 70B Instruct | 4.51 (2.61x) | 22.1 (1.51x) |
| Llama 3 8B Instruct | 3.86 (2.24x) | 21.2 (1.45x) |
| Llama 3 70B base | 1.77 | 13.3 |
| Llama 3 8B base | 1.62 | 12.8 |

Even GPT-4o's mean nominalization share is about 3.1% of words under the Biber definition, well below Sword's 5% and the linter's 0.06. The definitions differ (the linter's suffix regex counts more words), so the linter threshold cannot be checked against these numbers directly. It stays calibrated on the repo corpora.
