# Primary-source check of the 0.10.0 lexical, phrase and artifact evidence

Checked 2026-11-25 against the sources themselves, for every `source` string on a 0.10.0 group in `WORD_GROUPS`, `PHRASE_GROUPS` and `ARTIFACTS`, and for each number the research report (`2026-11-llm-writing-tells.md`), the group comments, the README or the CHANGELOG quote for a shipped rule. Most numbers hold. The problems are attribution (a figure credited to the wrong paper), scope (a creative-writing or one-user figure quoted without its scope), two artifact regexes that miss forms their own source documents, and one phrase regex that misses both of its documented examples.

Method. GitHub sources were read with `gh` (issue 53454 and its comment metadata, the `louisabraham/load-bearing` README, the berenslab excess-word CSV, slop-score data files, practitioner SKILL files). The PR-corpus numbers come from `analysis.js` as generated on 2026-11-25, loaded in Node. Wikipedia was read as raw wikitext through `action=raw` (main page revision 1387897756, Markup subpage revision 1387396182). arXiv papers were read as PDF text. Other pages went through WebFetch; economist.com refused automated fetches, so The Economist is checked through Daring Fireball and Wikipedia's citation of it. Each artifact and phrase regex named below was run in Node against the examples on the source page.

Artifact tokens are described in words here (for example "turnNsearchN"), because the linter fails on the literal tokens even inside code spans.
